Official public release of **Vin Vin's Studio v3.7.0** (Windows Desktop & Android APK):

- **Fixed All Download & Save Buttons** — Blob-based browser downloads (no silent data-URI truncation), instant Save without forcing an AI re-run first, native Windows Electron Save dialog, Android 10+ zero-permission direct MediaStore saving, and reliable same-origin `/api/*-download` links.
- **Multi-Person Studio (`+ Add Person`)** — Upload, edit, generate formal attire, add name tags/signatures, and crop 2+ different people independently — then print everyone together on the same Print Sheet (including 1-click "All People").
- **Multi-Page Print Sheets (`+ Add Page`)** — Add Page 2, Page 3, or tap "Move Overflow to New Page" when photos exceed one sheet — exporting true multi-page 300 DPI PDF, multi-page editable Word DOCX, and multi-page Direct Print.
- **Built-in Live Auto-Update Alerts** — Installed v3.6.0 Windows & Android apps automatically notify you to update to v3.7.0.
